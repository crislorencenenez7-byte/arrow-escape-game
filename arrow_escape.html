📘 Tutorial

  1. Tap an arrow whose path to the edge is clear.
  2. Arrows blocking one another must be removed in a safe order.
  3. You have 3 lives per level. Restarting resets the same puzzle.
  4. Use hints for 5 coins, undo for 2 coins, or shuffle for 10 coins.
  5. Shuffle only uses up/left arrows so the board remains solvable.
